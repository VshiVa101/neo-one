Owner: leo

## Purpose

Rapid ideation exercise to explore homepage layout variations before committing to digital wireframes.

---

## Method: Crazy 8s

### What is Crazy 8s?

**Crazy 8s** is a fast sketching exercise from Google Ventures' Design Sprint methodology:

- **8 concepts** in **8 minutes** (1 minute per sketch)
- **Goal**: Generate diverse ideas quickly without overthinking
- **Outcome**: Identify patterns, explore extremes, surface best directions

### Our Approach

**Session Date:** Monday, January 19, 2026

**Participants:** Leo (Designer) + Neo (Artist/Client)

**Focus:** Homepage layout concepts for Neo's artist portfolio site

**Constraint:** 2-page MVP (Home + Calendar) with hand-coded implementation

## Key Insights

### Pattern Analysis

**Gallery-First Approach (Across both participants):**

- **Leo's focus**: Gallery grid variations, navigation placement, content hierarchy
- **Neo's focus**: Artwork presentation styles, symbolic elements, atmospheric UI
- **Shared priority**: Art dominates, text minimal
- Masonry/grid layouts emerged as dominant pattern from both participants

**Navigation Style (Split Preference):**

- **Symbolic navigation**: Eye icon, minimal text (3/8 sketches)
- **Text-based navigation**: Traditional menu (2/8 sketches)
- **Hybrid**: Icons + labels (3/8 sketches)

### Visual Hierarchy Consensus

- Art should dominate the viewport
- Text/copy kept minimal (brand over explanation)
- Dark aesthetic preferred (atmospheric over clean)

### Interaction Ideas

- Hover states for gallery items
- Symbolic wayfinding instead of traditional UI
- Immersive entry experience (advisement screen)

---

## Decisions Made

### Design Direction

Based on Crazy 8s patterns, we decided:

1. **Gallery-First Homepage**
    - Dynamic gallery as primary content (CMS-driven)
    - Artwork takes 70%+ of viewport
    - Minimal text/branding above fold
2. **Symbolic Navigation**
    - Eye icon for primary navigation
    - Symbolic language aligned with brand (underground, cryptic)
    - Text labels minimal or hidden until hover

### Design Direction (cont.)

1. **Dark Atmospheric UI**
    - Black/dark gray base
    - Art as color source
    - High contrast for readability
2. **Entry Experience**
    - Advisement/warning screen before main site
    - Sets tone (raw, uncensored, intentional)
    - Filters audience (self-selection)

**Site Architecture:**

- Confirmed 2-page structure (Home → Calendar)
- Gallery-Shop hybrid approach validated
- Linktree integration on Calendar page

**Feature Prioritization:**

- Dynamic Gallery = P0 (critical MVP)
- Symbolic navigation = P1 (high-value MVP)
- Immersive atmosphere features = P1 (custom cursor, soundtrack)

### Wireframe & Mockup Evolution

**Paper Wireframes (Week 3):**

- Started with top 3 Crazy 8s concepts
- Refined masonry grid layout
- Developed symbolic nav system

**Hi-Fi Mockups (Week 5):**

- Dark UI with artwork as focal point
- Minimal text, maximum visual impact
- Advisement screen as entry point

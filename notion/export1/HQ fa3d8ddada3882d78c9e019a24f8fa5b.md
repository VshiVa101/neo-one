# Asset Archive

<aside>
💡

**Come caricare file “dentro un blocco” o “ in linea”**

**Passo 1:** Clicca con il mouse in zona vuota qui sotto 

**Passo 2:** Scrivi `/file` e premi Invio sulla tastiera (apparirà suggerimento già da  `/`)

**Passo 3:** Clicca su "Upload" nella finestra che compare

**Passo 4:** Seleziona i file .TIF dal tuo computer

**Passo 5:** Fatto! Il file comparirà qui sotto dopo il tempo di upload

**OPPURE (più veloce):** Trascina i file .TIF direttamente qui sotto con il mouse (drag & drop)

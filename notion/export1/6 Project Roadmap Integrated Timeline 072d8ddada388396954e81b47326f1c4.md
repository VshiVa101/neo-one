## 🛠️ Vibe Coding Strategy with Antigravity

### Tech Stack

- **IDE:** Antigravity (AI-assisted coding)
- **Languages:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Optional Framework:** Lightweight (Alpine.js, Astro, 11ty) if needed for templating
- **Version Control:** Git + GitHub
- **Hosting:** GitHub Pages / Netlify / Vercel (free tier)
- **CMS Logic:** JSON data files + JavaScript templating OR static site generator
- **Forms:** Formspree / Netlify Forms / EmailJS (no backend required)
- **3D Eye:** Spline embed OR Canvas/Three.js with Antigravity assistance
- **Performance:** Native lazy loading, Intersection Observer, CSS variables

### Antigravity Prompt Strategy

**Effective prompts for vibe coding:**

- "Generate semantic HTML5 structure for artist portfolio with hero, gallery clusters, calendar, and contact sections"
- "Create CSS grid system for artwork gallery with cluster categories (cards, comics, illustrations, stickers, merch)"
- "Build responsive navigation with hamburger menu and smooth scroll animations"
- "Generate JSON schema for artwork database with fields: title, year, medium, description, image URL, cluster type, price, status"
- "Create modal component with hi-res image zoom, backstory reveal, and add-to-cart form using vanilla JS"
- "Implement 12-month calendar grid layout with event population from JSON data"
- "Optimize images with lazy loading and srcset for responsive design"
- "Generate sitemap.xml and meta tags for SEO optimization"
